# 界面升级与全站验收记录

## 结论

本轮完成界面升级、全页面操作回归、27 个商品/详情模块的素材与文字传递验证，以及 9 张真实图片和 1 个真实 WebM 的生成、预览、下载检查。不能判定“所有功能已完全上线、全部效果达到预期”。新版上传、找回密码、审核套餐接口尚未部署；灵感创作的真实请求失败；买家秀和精修存在超出编辑范围的问题。

## 界面完成项

- 暖白背景，统一深紫色主按钮；主图、详情、AI 工具、灵感、Live 采用克制的独立浅色标识。
- 二级导航补图标；登录后首页改为带工具图标、草稿状态及图片预览的卡片。
- 上传入口、生成空状态增加视觉引导；图片库、任务统计、价格、账户及登录页保持一致的圆角与间距。
- 保留此前修正的宽屏边界、横向模块名称和登录/找回密码居中。修正手机旧样式把导航按钮撑成整行的问题。
- 全屏大图通过顶层弹层展示，避免被预览容器遮住；支持 Esc、焦点返回。

## 本地修复的缺陷

| 问题 | 处理 | 验证 |
| --- | --- | --- |
| 读取图片缓存触发任务恢复归一化，可能改写 processing | 增加按 owner 的只读任务快照；图库读取不写任务状态 | 进行中任务缓存读前后不变 |
| 旧账号请求晚到、新上传缓存被较早列表覆盖 | 账号版本和订阅取消隔离；显式保存优先 | A/B 切换、关闭重开、新保存与旧读取竞态测试 |

| 取消排队后仍可能调用供应商 | 执行/排队/请求/上传使用同一个取消信号 | 取消后不新增 provider 调用 |
| 过期活动任务仍冻结预留积分 | 执行期限与租约联动，取消并释放；按时结果延后结算不误伤 | 过期、迟到结果、结算延迟测试 |

| 素材抓取只有局部超时 | 覆盖整条素材请求期限，取消不使用的响应流，保留大小限制 | 提取、保存、上传、列表及流式上限测试 |
| 下载失败没有提示、下载 URL 过早释放 | 显示下载失败；延后释放 Blob URL | 浏览器实际 download 事件与本机文件验证 |
| 本地预览连接真实后台时仍可模拟“付款成功” | 真实账号/真实网页后台禁止模拟购买加分 | 无 Paddle 配置时余额不变 |
| 原子结算模式 webhook 中断后卡在 processing | 允许依赖幂等 RPC 安全恢复 | 回调重放、并发只入账一次；旧分支尚需迁移 |
